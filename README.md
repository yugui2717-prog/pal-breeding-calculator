幻兽帕鲁配种计算器：输入父母/目标，秒查配种结果（含变异



功能

正向查询：输入父母帕鲁 → 得到子代

反向查询：输入目标帕鲁 → 知道父母组合

变异规则：支持变种帕鲁配种（如幻冬兽→唤夜兽）

查询历史：自动保存查询记录（本地）

留言板：所有玩家可见；国内网络下留言仅保存在本地

使用说明

打开网址：https://yugui2717-prog.github.io/pal-breeding-calculator/

怎么用：打开网址 → 选帕鲁 → 点查询

技术栈

前端：HTML / CSS / JavaScript

后端：Cloudflare Workers（留言板）

部署：GitHub Pages
