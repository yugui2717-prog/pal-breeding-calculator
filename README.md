幻兽帕鲁配种计算器：输入父母/目标，秒查配种结果（含变异



功能

功能 1：正向查询（输入父母帕鲁，可得子代帕鲁） / 反向查询（输入要查询的帕鲁，可以知道该帕鲁是由哪两种帕鲁杂交获得）/ 变异规则（与变种帕鲁相关，如：幻冬兽变种唤夜兽）

功能 2：查询历史（可保留查询记录）

功能 3： 留言板（可留下自己的想法，所有用户都可以看到你说了什么，国内网络留言仅保存在本地，无法互通留言）



使用说明

打开网址：https://yugui2717-prog.github.io/pal-breeding-calculator/

怎么用：打开网址 → 选帕鲁 → 点查询

技术栈

前端：HTML / CSS / JavaScript

后端：Cloudflare Workers（留言板）

部署：GitHub Pages
